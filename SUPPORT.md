# Boksa support

Questions, problems and ideas are welcome at
[GitHub Issues](https://github.com/sungju/boksa-extension/issues)
(a free GitHub account is needed).

**Issues are public.** Please leave out names, customer data, case numbers and
anything else that should not be seen by everyone. Reproduce the problem with
made-up text instead.

## Before reporting

- **Nothing happens on the shortcut:** open `chrome://extensions/shortcuts` and
  set Boksa's key to Control+Shift+9. On macOS use Control, not Command. The
  toolbar button does the same thing.
- **A local file cannot be copied:** open Boksa's Details page at
  `chrome://extensions` and turn on **Allow access to file URLs**.
- **Chrome pages, the Web Store and other extensions' pages** cannot be copied.
  Chrome does not let extensions run there.
- **The paste looks different:** the default **Paste target** is Salesforce +
  Customer Portal. For any other editor choose **Any editor** in Boksa's options
  (right-click the toolbar button → Options), or try another **Code blocks**
  choice. Some editors remove styles whatever is pasted.

The [README](https://github.com/sungju/boksa-extension#readme) has the full guide.

## What to include

- Boksa's version (shown at `chrome://extensions`), and your Chrome and system versions
- The Boksa options you use
- Where you copied from and where you pasted
- A small Markdown sample, what you expected and what you got

# Boksa 지원

질문, 문제, 제안은 [GitHub Issues](https://github.com/sungju/boksa-extension/issues)에
남겨 주세요(무료 GitHub 계정이 필요합니다).

**이슈는 누구나 볼 수 있습니다.** 이름, 고객 정보, 케이스 번호처럼 공개하면 안 되는
내용은 빼고, 꾸며낸 예문으로 문제를 재현해 주세요.

## 먼저 확인할 것

- **단축키가 동작하지 않을 때:** `chrome://extensions/shortcuts`에서 Boksa의 키를
  Control+Shift+9로 지정하세요. macOS에서는 Command가 아니라 Control입니다. 툴바
  버튼도 같은 일을 합니다.
- **로컬 파일이 복사되지 않을 때:** `chrome://extensions`의 Boksa 세부정보 페이지에서
  **파일 URL에 대한 액세스 허용**을 켜세요.
- **Chrome 내부 페이지, 웹 스토어, 다른 확장 프로그램의 페이지**는 복사할 수 없습니다.
  Chrome이 확장 프로그램의 실행을 막습니다.
- **붙여넣은 모양이 다를 때:** **붙여넣을 곳**의 기본값은 Salesforce + 고객 포털입니다. 다른
  편집기에서는 Boksa 옵션(툴바 버튼 우클릭 → 옵션)에서 **모든 편집기**를 고르거나
  **코드 블록**을 바꿔 보세요. 어떤 편집기는 무엇을 붙여넣어도 스타일을 제거합니다.

## 함께 적어 주세요

- Boksa 버전(`chrome://extensions`에 표시), Chrome과 운영체제 버전
- 사용 중인 Boksa 옵션
- 복사한 곳과 붙여넣은 곳
- 짧은 Markdown 예문, 기대한 결과와 실제 결과

개인정보처리방침: [PRIVACY.md](https://github.com/sungju/boksa-extension/blob/main/PRIVACY.md)
